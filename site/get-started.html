Get started with AI SUS

Install AI SUS where you work, pick the agent you already use, and follow the map back to code. Local maps work without a AI SUS account.

Install AI SUS

Choose an editor extension, install the skills for your coding agent, or add the Claude Code plugin. You can open a map in the editor or in its standalone diagram page.

Install the editor extension

Find AI SUS: Code-Linked Architecture Maps in the VS Code Extensions view. In Cursor or Devin Desktop, use Open VSX or choose Install from VSIX… with the VSIX from the latest release.

Open a repository and click the AI SUS icon in the Activity Bar. The setup checklist names anything your chosen agent still needs.

Install the IntelliJ IDEA plugin

Find AI SUS in JetBrains Marketplace. Open a project and choose the AI SUS tool window to generate or open its architecture map.

Install the skills for Codex or Claude Code

From your repository, run the same installation command for either CLI. Follow the prompts to add AI SUS's skills to the agent you use. Node.js 18 or newer is required to generate a map.

TERMINAL
npx skills add xplus2g4/sustain

Open the repository in Claude Code and run /sustain-architecture, or open it in Codex and run $sustain-architecture. Add a focus after the skill name if you want to map one part of the code.

Install the Claude Code plugin

Download sustain-skills.zip from the latest release. Unzip it in a terminal:

TERMINAL
unzip sustain-skills.zip -d sustain-skills

Then run these commands in Claude Code:

CLAUDE CODE · ADD MARKETPLACE
/plugin marketplace add ./sustain-skills
CLAUDE CODE · INSTALL PLUGIN
/plugin install sustain@sustain
The editor extension opens and checks maps. Agent skills generate them. You can install either route on its own or use them together.

Generate a map

In the AI SUS sidebar, choose Generate and name a focus if you want one, such as “checkout flow.” AI SUS uses the agent and account you already have. You can also start the skill directly:

Use the installed skill in Claude Code

Open Claude Code in the repository and enter:

CLAUDE CODE
/sustain-architecture checkout flow

The focus is optional. The skill creates the map and checks its citations before saving.

Use the installed skill in Codex

Open Codex in the repository and enter:

CODEX
$sustain-architecture checkout flow

The focus is optional. Open the resulting map in AI SUS after the agent finishes.

Launch Devin from AI SUS

Choose Devin in the Generate menu. AI SUS launches the CLI with the installed skill and opens the resulting map when it is ready.

Copy a prompt for another agent

For GitHub Copilot, Cursor’s agent, Gemini CLI, OpenCode, or Devin Desktop, choose Copy prompt for… in AI SUS and paste it into your agent. The prompt points the agent at the installed skill.

Agent generation uses your agent’s tokens or subscription allowance. Opening a map and checking citation freshness do not make an AI call.

Inspect the code behind a box

Open the new map from AI SUS’s Maps list. Click any component to open its cited file and lines in the other editor column. Hover to read the description and every citation.

  1. Start with the entrypoint for the feature you are learning.
  2. Follow an arrow to a connected component.
  3. Open the source and check that the description matches the implementation.
The diagram is useful because each claim has a route back to source. If a box looks wrong, follow its citation and flag it in AI SUS.

Check what changed

AI SUS checks cited code against your working copy when you open the map and as you edit. A box is marked fresh, moved, edited, or missing. The check uses no agent tokens.

  1. Open the map after a code change.
  2. Review the freshness state and changed-code coverage.
  3. Choose Refresh to send only changed or missing parts back to your agent.

Share the map with your team

Commit the accepted map with the repository to make it available for local and pull request checks. The GitHub Action can compare each pull request with that map without running an agent.

When your team wants web map pages, PR history, dashboards, and read-only share links, opt in to AI SUS Cloud. Uploads can come from the CLI or the Action. Source files stay on your machine or CI runner.
